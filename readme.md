# Módulo 8 — Animaciones y Full Responsive

## AlexBanexx Soluciones IT

### Objetivo
Mejorar la experiencia visual y la adaptación responsive del sitio web, aplicando animaciones y optimizando los estilos SCSS, sin modificar el repositorio original.

### Tecnologías
- HTML5, CSS3 y SCSS.
- Bootstrap.
- AOS (Animate On Scroll).
- Git y GitHub.

### Implementaciones
- **Mixins SCSS:** reutilización de estilos y transiciones.
- **Animaciones AOS:** efectos visuales al desplazarse por la página.
- **Responsive:** adaptación de navegación, tarjetas, imágenes, formularios y mapas a móviles, tablets y escritorio.
- **Compilación SCSS:** generación de `css/styles.css` desde `scss/main.scss`.

### Ramas Git
- `agregar-mixin-animacion`
- `agregar-animacion-aos`
- `control-responsividad`
- `main`: integración de las funcionalidades.

### Compilación

```bash
npx sass scss/main.scss css/styles.css
```

### Validación
Verificar las cinco páginas en resoluciones de 375 px, 768 px y 1024 px o superiores, comprobando navegación, animaciones y ausencia de desbordamientos.
